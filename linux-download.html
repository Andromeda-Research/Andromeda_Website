Universal Linux Distribution

Install Andromeda on Any Linux Distro

Choose your preferred packaging format below. All binaries are cryptographically signed, stripped, and packaged with zero cloud telemetry.

Ubuntu / Debian / Mint
Native .deb package

Recommended for Ubuntu 22.04+, Debian 12+, Linux Mint, and Pop!_OS. Resolves all WebKitGTK dependencies in one shot.

sudo apt install ./andromeda-writer_amd64.deb
Download .deb (64-bit)
Flatpak / Flathub
Sandboxed Universal

Full sandboxing and seamless automatic background updates across all modern Linux desktops.

flatpak install flathub dev.andromeda.Writer
View on Flathub
Snap Store
Canonical Snapcraft

One-line install for Ubuntu, Manjaro, Zorin, and any distribution with snapd support.

sudo snap install andromeda-writer
Snap Store Page
Universal AppImage
Zero Install • Portable

Single executable that runs immediately on any Linux distro without root privileges or package manager locks.

chmod +x Andromeda-x86_64.AppImage && ./Andromeda-x86_64.AppImage
Download .AppImage
Arch Linux / Manjaro
AUR Package

Available via the Arch User Repository (AUR). Build and update effortlessly using yay or paru.

yay -S andromeda-writer-bin
View AUR Package
Fedora / RHEL / openSUSE
RPM Package

Native RPM package for Fedora 38+, Red Hat Enterprise Linux, CentOS Stream, and openSUSE.

sudo dnf install ./andromeda-writer-x86_64.rpm
Download .rpm

📦 Automated Dependency Resolution & Package Integrity

Andromeda Writer uses the native system web rendering engine (WebKitGTK). When installed via .deb, .rpm, Flatpak, or Snap, all required libraries (libwebkit2gtk-4.1-0, libgtk-3-0) are automatically downloaded and configured in one shot with zero manual intervention.
